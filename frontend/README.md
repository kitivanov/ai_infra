# AI Infra - Frontend

Клиентское SPA-приложение платформы ИИ-агентов на **React, TypeScript и Vite**.

## Возможности

- Регистрация и вход.
- Каталог агентов, просмотр конфигурации и чат.
- Создание и редактирование собственных агентов.
- Управление конфигурациями Model, RAG и MCP.

## Стек

- React + TypeScript + Vite - интерфейс и сборка.
- React Router - маршрутизация.
- Zustand - состояние авторизации, агентов, ресурсов и чатов.
- Axios - HTTP-клиент и передача JWT.

## Структура `src/`

- `pages/` - страницы приложения.
- `components/` - переиспользуемые UI-компоненты.
- `stores/` - Zustand-хранилища и операции с API.
- `api/` - HTTP-клиент и обработка ошибок.
- `utils/` - вспомогательные функции.
- `main.tsx` - маршрутизация и точка входа.
- `styles.css` - стили.

## Локальный запуск

Из каталога `frontend/`:

```bash
npm install
npm run dev
```

Проверка сборки:

```bash
npm run build
```

По умолчанию интерфейс доступен на http://localhost:5173. Для настройки API используется `VITE_API_URL`; без неё запросы идут через `/api` (прокси Vite). Не помещайте секреты в `VITE_*`.

Запуск всей платформы через Docker Compose описан в корневом README.
