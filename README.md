# AI Infra - корпоративная платформа ИИ-агентов

**AI Infra** - Приложение для централизованного создания, настройки и использования ИИ-агентов. Владелец агента определяет его назначение, системный промпт и подключённые ресурсы. Другие авторизованные пользователи могут открыть готового агента и общаться с ним, не изменяя его конфигурацию.

## Возможности

- Регистрация и вход пользователей с JWT-аутентификацией.
- Каталог агентов: создание, просмотр, редактирование и удаление.
- Разграничение прав: изменять и удалять агента может его создатель; пользоваться агентом могут другие авторизованные пользователи.
- Управление конфигурациями **Model**, **RAG** и **MCP** и привязка ресурсов к агентам.
- Настройка модели: название, адрес API, ключ и дополнительные сведения.
- Чат с агентом: создание диалогов, просмотр сообщений и отправка запросов к настроенному LLM-провайдеру.

## Технологический стек

| Компонент | Технологии |
| --- | --- |
| Backend | Python, FastAPI, SQLAlchemy, Pydantic |
| База данных | PostgreSQL 16 |
| Авторизация | JWT, хеширование паролей |
| Frontend | React, TypeScript, Vite |
| Клиентское состояние и HTTP | Zustand, Axios |
| Инфраструктура | Docker, Docker Compose |
| Интеграция с ИИ | HTTP-запросы к настроенному LLM API |

## Как устроена платформа

```text
Пользователь → React frontend → FastAPI backend → PostgreSQL
                                  │
                                  └── Chat service → LLM API

Владелец → создаёт Agent → задаёт System Prompt и Model / RAG / MCP
Другой пользователь → открывает Agent → использует Chat
```

**Основные сущности:**

- **User** - учётная запись пользователя.
- **Agent** - ИИ-помощник с владельцем, описанием, системным промптом, статусом и ссылками на ресурсы.
- **Model** - конфигурация подключения к языковой модели.
- **RAG** - конфигурация источника знаний (без реального retrieval в текущем MVP).
- **MCP** - конфигурация интеграции с инструментами (без выполнения MCP-вызовов в текущем MVP).
- **Chat / Message** - чат пользователя с агентом и его сообщения.

### Права доступа

В приложении пока что нет отдельной административной роли: **владелец агента** - пользователь, создавший конкретного агента. Он может менять и удалять его конфигурацию. Остальные авторизованные пользователи могут просматривать агента и использовать его в чате, но не редактировать или удалять чужого агента.

## Запуск через Docker Compose

**Требования:** установленные Docker и Docker Compose.

Из корневой директории проекта выполнить:

```bash
docker compose up --build
```

Compose запускает три сервиса: PostgreSQL, FastAPI backend и React frontend.

| Сервис | Адрес |
| --- | --- |
| Веб-интерфейс | http://localhost:5173 |
| Backend API | http://localhost:8000 |
| Swagger UI | http://localhost:8000/docs |
| ReDoc | http://localhost:8000/redoc |
| PostgreSQL (с хост-машины) | localhost:5432 |


### Конфигурация

Backend использует переменные окружения:

| Переменная | Назначение |
| --- | --- |
| `DATABASE_URL` | Строка подключения к PostgreSQL |
| `JWT_SECRET_KEY` | Секрет подписи JWT |
| `ACCESS_TOKEN_EXPIRE_MINUTES` | Время жизни access token |
| `FRONTEND_ORIGIN` | Разрешённый origin frontend для CORS |
